# Sunset-Depths-Parallax

Single-page fantasy scene built with layered scrolling and GSAP parallax effects.

## Stack

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger

## Run

Open `index.html` or start a local server:

```bash
python -m http.server 5500
```

## Structure

```text
css/    Page styles
img/    Base and parallax layers
js/     Animation setup
libs/   Local GSAP libraries
```

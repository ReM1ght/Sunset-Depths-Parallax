# Sunset Depths Parallax

A fantasy-themed scrolling page with layered scenes and smooth parallax motion.

**Live demo:** https://rem1ght.github.io/Sunset-Depths-Parallax/

## Technologies

- HTML5
- CSS3
- JavaScript
- GSAP
- ScrollTrigger

## Local Preview

Open `index.html` directly or serve the directory locally:

```bash
python -m http.server 5500
```
